## Корекции

Оркестраторот сега го замрзнува commit-от добиен во preflight и го проверува
и пред и по човечкото внесување на approval token-от. Ако HEAD се смени во
тој период, поправката се одбива и се активира детерминистичкото враќање.

Live wrapper-от дополнително ги повикува двете Python компоненти со
`python3 -m experiments...`, така што независниот verifier добива стабилен
package import path без да зависи од надворешен `PYTHONPATH`.

Финален позитивен резултат бара ново чисто извршување со ист commit во
preflight и approval записот, проследено со `verification_status: PASS`.
